# TaskCampus

Aplicación web para la gestión de tareas desarrollada con React y Vite.

## Requisitos previos
* Node.js
* npm

## Instalación y ejecución
Para instalar las dependencias e iniciar el servidor de desarrollo local de forma secuencial, ejecuta en la terminal:

```bash
npm install && npm run dev
```

## Scripts de verificación
* `npm run build`: Compila y empaqueta la aplicación para producción.
* `npm run lint`: Ejecuta el análisis estático de código con ESLint.
